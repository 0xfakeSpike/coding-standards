# 文件处理

本文讲上传、路径、下载、压缩包和图片。单一防线都不够，这些规则要组合使用。语言相关的路径 API 见 `languages/<语言>/security.md`。

## 上传

**适用：** 高风险（本节全部规则）

### 先定义每个上传功能的边界 【必须】

为每个上传入口写明允许的类型、扩展名、最大大小（含解压后大小），以及下载时的处理方式。上传前先完成认证和授权。

**来源：** OWASP ASVS、OWASP 文件上传速查表

### 类型校验要依据内容 【必须】

解码文件名后用白名单校验扩展名，再按文件内容校验类型。不信任扩展名和 `Content-Type`。只开放业务需要的类型，优先选风险低的类型。

| 检查 | 能防住 | 局限 |
|---|---|---|
| 扩展名白名单 | `.php`、双扩展名 `.jpg.php` | 不代表内容安全 |
| `Content-Type` | 用户误传 | 可以任意伪造 |
| 文件头 | 简单伪装 | 容易绕过，不能单独使用 |
| 专用库解析或重写 | 结构不符的文件 | 解析器本身也面对不可信输入 |

**原因：** 单靠黑名单容易被大小写、空字节或替代扩展名绕过。

**来源：** OWASP 文件上传速查表、OWASP ASVS

### 重新生成文件名 【必须】

存储名由服务端用随机值生成，原始文件名只作为元数据保存，并限制长度和字符。必须保留用户文件名时，禁止开头的点和连字符、连续的点、冒号和路径分隔符。

**原因：** 文件名可能带路径穿越、覆盖已有文件，或进入脚本和 HTML 造成注入。

**来源：** OWASP 文件上传速查表、OWASP ASVS

### 存储隔离且不可执行 【必须】

文件优先放在独立主机或对象存储中，其次放在 Web 根目录之外。上传目录不可执行，文件权限最小化。防止用户上传 `.htaccess`、`web.config` 这类目录配置文件。

**原因：** 上传的脚本一旦能被服务器执行，就是远程代码执行。

**来源：** OWASP 文件上传速查表、OWASP ASVS

### 限制大小和总量 【必须】

在读入内存之前限制单文件大小，流式处理大文件。按用户限制文件总数和总容量，防止存储被耗尽。上传和下载都要限频。

**来源：** OWASP 文件上传速查表、OWASP ASVS

### 预签名上传同样受约束 【必须】

客户端直传对象存储时，服务端签发的地址要短期有效，并限定对象键、大小和类型。文件上传后仍要校验内容，通过校验后才对外可见。

### 高风险场景扫描恶意内容 【推荐】

来自不可信来源的文件接入病毒扫描后再提供下载。公开内容提供举报渠道，必要时在沙箱中人工审核。

**来源：** OWASP ASVS、OWASP 文件上传速查表

## 路径穿越

### 不用用户输入拼接路径 【必须】

优先用内部 ID 映射到服务端生成的路径。

反例：

```http
GET /files?name=../../etc/passwd HTTP/1.1
```

正例：

```http
GET /files/7f3a9c HTTP/1.1
```

**来源：** OWASP ASVS

### 必须用用户路径时规范化后校验 【必须】

先解码，再解析为规范化的绝对路径，确认仍在允许的根目录之内，再访问。比较时按完整路径段判断，避免 `/data/uploads-evil` 通过 `/data/uploads` 的前缀检查。解析符号链接后再判断。

**原因：** 只过滤 `../` 容易被编码和嵌套形式绕过。

**来源：** OWASP ASVS

## 下载

### 每次下载都校验权限 【必须】

文件访问走授权校验，不靠路径难猜。签名下载地址短期有效，生成前先授权。多租户路径按租户隔离，见 [授权](authorization.md)。

**来源：** OWASP 授权速查表、OWASP 多租户安全速查表

### 让浏览器按附件处理 【必须】

**适用：** 高风险

用户上传内容用 `Content-Disposition: attachment` 下载，指定服务端确定的文件名，并加 `X-Content-Type-Options: nosniff`。文件名按 RFC 6266 编码，防止响应头注入。

```http
Content-Type: application/octet-stream
Content-Disposition: attachment; filename="report.pdf"; filename*=UTF-8''%E6%8A%A5%E5%91%8A.pdf
X-Content-Type-Options: nosniff
```

**原因：** 用户上传的 HTML 或 SVG 在业务域名下渲染时，脚本能读取站点数据。

**来源：** OWASP ASVS

### 用户内容使用独立域名 【推荐】

需要在线预览时，用与主站不同的域名提供访问，并配置限制性的 CSP。

**来源：** OWASP ASVS

## 压缩包

### 优先不接受压缩包 【推荐】

压缩包可以包含任意类型的文件，攻击方式很多。确需接受时，遵守本节全部规则。`docx`、`odt` 这类文件也是压缩格式。

**来源：** OWASP 文件上传速查表、OWASP ASVS

### 解压前检查总量 【必须】

解压前检查解压后的总大小和文件数量。解压时按实际写出的字节计数，超限立即中止，不信任包头声明的大小。限制嵌套层数。

**原因：** 压缩炸弹能用很小的文件耗尽磁盘和内存。

**来源：** OWASP ASVS、OWASP 文件上传速查表

### 解压时校验包内路径 【必须】

包内路径视为不可信，规范化后确认位于目标目录内，否则拒绝（Zip Slip）。不接受符号链接。解压到隔离的临时目录，逐个校验其中文件的类型后再使用。

**来源：** OWASP ASVS

## 图片处理

**适用：** 高风险（本节全部规则）

### 处理前限制像素尺寸 【必须】

解码前读取宽高，超过上限直接拒绝。文件很小的图片也可能解码出极大的位图。

**来源：** OWASP ASVS

### 重新编码并清除元数据 【推荐】

解码后重新编码为允许的格式，删除 EXIF 等元数据，其中可能含定位信息。重写不能保证清除全部恶意内容。

**来源：** OWASP 文件上传速查表、OWASP ASVS

### 隔离图片处理进程 【推荐】

图片库在解析不可信输入，要及时升级，并在资源受限的隔离环境中运行，设置超时和内存上限。

**来源：** OWASP 文件上传速查表

### SVG 按脚本内容对待 【必须】

SVG 可以包含脚本。净化后只保留安全的标签和属性，或转成位图，或只作为附件下载。

**来源：** OWASP ASVS
